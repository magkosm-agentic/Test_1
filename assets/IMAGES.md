# Photos for The Paperclip Protocol

Drop each file into this folder under the exact name below and the deck picks it up on reload.
Until a file is present, its slot renders as a labelled "archive photo, not on file" card, so the
deck is presentable either way.

Every photo listed is public domain or a Bundesarchiv image under CC BY-SA 3.0 DE, and all are on
Wikimedia Commons. Search Commons for the title given (or the category when the exact file name is
uncertain), open the file page, and download the 1,000 to 1,500 px version. Crop portraits roughly
3:4; backgrounds can stay as they are. Keep each file under about 400 KB.
